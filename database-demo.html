2. Data Dictionary (ตารางข้อมูลในระบบ)

2.1 USER (ผู้ใช้งาน)

AttributeTypeKeyDescription
user_idINT / UUIDPKรหัสผู้ใช้
username / emailVARCHAR-ชื่อผู้ใช้ / อีเมล
created_at / updated_atTIMESTAMP-เวลาที่สร้าง/แก้ไข

2.2 CLOTHING_ITEM (รายการเสื้อผ้า)

AttributeTypeKeyDescription
item_idINT / UUIDPKรหัสเสื้อผ้า
category_idINT / UUIDFKอ้างอิงประเภทเสื้อผ้า (CATEGORY)
user_idINT / UUIDFKอ้างอิงผู้แต่งกาย/เจ้าของ (USER)
item_name / color / brandVARCHAR-รายละเอียดเสื้อผ้า

2.3 OUTFIT & OUTFIT_ITEM (ชุดแต่งกาย และ เสื้อผ้าในชุด)

AttributeTypeKeyDescription
outfit_idINT / UUIDPKรหัสชุดแต่งกาย
user_idINT / UUIDFKเจ้าของชุด (USER)
item_idINT / UUIDFKรายการเสื้อผ้าที่รวมในชุด (OUTFIT_ITEM)

2.4 CALENDAR_LOG, WEATHER & OCCASION (การบันทึกปฏิทิน สภาพอากาศ และโอกาส)

AttributeTypeKeyDescription
log_idINT / UUIDPKรหัสบันทึกปฏิทินการแต่งกาย
outfit_idINT / UUIDFKชุดที่ใส่ในวันนั้น (OUTFIT)
weather_idINT / UUIDFKสภาพอากาศวันนั้น (WEATHER)
occasion_idINT / UUIDFKโอกาส/งานที่ไป (OCCASION)

3. AUDIT LOG (ประวัติการใช้งาน)

บันทึกการกระทำของผู้ใช้เพื่อความปลอดภัยและตรวจสอบย้อนหลัง (USER 1:N AUDIT_LOG)

AttributeTypeKeyDescription
log_idINT / UUIDPKรหัสบันทึก
user_idINT / UUIDFKผู้กระทำกิจกรรม
action / record_id / table_nameVARCHAR-การกระทำ, ตารางที่ถูกแก้, ข้อมูลเก่า-ใหม่
